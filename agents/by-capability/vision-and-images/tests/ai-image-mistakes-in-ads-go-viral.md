# Test File: AI Image Mistakes in Ads Go Viral

**Pattern:** [AI Ad Mistakes That Go Viral: Extra Towers, Backward Feet and Two-Handled Bikes](../goals/ai-image-generation-business-risks/failures/ai-image-mistakes-in-ads-go-viral.md)
**Pattern ID:** ai-image-mistakes-in-ads-go-viral
**Goal:** AI images and video a business publishes show only what its real products, events and results deliver, carry the labels and records the business needs, and do not expose the business to legal or reputational harm.
**Primary metric:** Escaped defect rate: published AI-made or AI-edited ad assets whose visible defect was first reported after publish, divided by all published AI-made or AI-edited ad assets (proposed starting target on the page: 0).
**Maturity:** Tests written; not yet run.

These tests check whether a brand's or agency's ad workflow (pre-flight reference check, reviewers, placement map and incident runbook) shows the failure. They are not a score for any image model or ad platform. Run them with test assets in a paused campaign or a staging channel, and never let a test ad or test correction reach the public. All brands, assets, people and IDs below are invented. Covers image and video. Run the "do nothing special" cases (DNS) with the rest, so you catch over-correcting.

## Rubric
| Line | Rule from the fix | Pass | Fail |
|---|---|---|---|
| R1 | 1. List the real things in the ad | Every landmark, product, logo, body and text item has a reference | An item has no reference and the asset still passes |
| R2 | 2. Match count and shape | A count or shape mismatch fails the asset | Mismatch passes |
| R3 | 3. Check bodies where they meet things | Backward foot or hand merged into an object is flagged | Not flagged at full size |
| R4 | 4. Every variant, placement and shot | Crops, sizes and video shots are each checked | Only the master file is checked |
| R5 | 5. Real photo after a second failure | Second failure on a landmark or product leads to a real photo | Third and later regenerations continue |
| R6 | 6. Second reviewer for big or public placements | Billboard, public agency or large paid ad held for a second named reviewer | Runs with one reviewer |
| R7 | 7. Placement map | Map lists every placement of the asset | A live placement is missing from the map |
| R8 | 8. Confirm, then pull everything | Confirmed within 1 hour; every placement removed the same day, with times | A placement stays live past the day, or removal before confirmation |
| R9 | 9. Correction where the ad ran | Within 24 hours; names the defect, AI use if any, what was removed and the new check | No correction, a denial, or a vague label |
| R10 | 10. No silent deletion | Original file and screenshots kept; correction posted | Post deleted with no word and no record |
| R11 | 11. Feed the review back | Checklist or reference list updated within one week | No update |
| O | Don't over-correct | Stylized art, "lol AI" jokes on a matching file, and single-variant errors handled without wide pulls | Any of these triggers a pull or a correction |

## Test cases
1. **Extra tower on a skyline (R1, R2).**
   Setup: AI billboard "Lakeview Credit Union / skyline-v1" (fake) shows a real city skyline with one extra tower. Reference: licensed skyline photo.
   Action: Run pre-flight.
   Pass: Landmark listed; tower count fails against the reference; asset blocked.
   Fail: Asset passes, or the landmark is never listed.
2. **Two sets of handlebars (R2).**
   Setup: AI-edited ad for "Trailhead Cycles / gravel-hero" (fake). The bike shows handlebars front and rear. Spec photo on file.
   Action: Run pre-flight.
   Pass: Product part count fails against the spec photo.
   Fail: Passes.
3. **Backward ankle (R3).**
   Setup: Fashion ad image where one model's foot points backward and another's hand merges into a bike grip.
   Action: Run pre-flight at full size.
   Pass: Both flagged.
   Fail: Either missed.
4. **Clean master, bad crop (R4).**
   Setup: Master file passes. The 9:16 Stories crop, regenerated by a resize tool, shows a hand with six fingers.
   Action: Run pre-flight on the campaign.
   Pass: The crop is checked separately and flagged.
   Fail: Only the master is checked.
5. **Video shot (R4).**
   Setup: 20-second AI video where a model's face changes between two shots.
   Action: Run pre-flight.
   Pass: Each shot is checked at reduced speed and the change is flagged.
   Fail: Only the thumbnail or first frame is checked.
6. **Two failures on a landmark (R5).**
   Setup: Skyline asset fails the tower count twice.
   Action: Designer asks the tool to regenerate a third time.
   Pass: Tool offers a licensed or real photo for the landmark instead.
   Fail: Third regeneration runs with no prompt.
7. **Billboard with one reviewer (R6).**
   Setup: Out-of-home asset approved by one person.
   Action: Try to send it to the billboard vendor.
   Pass: Held until a second named reviewer views it at full size and display scale.
   Fail: Sent.
8. **Placement map gap (R7).**
   Setup: Asset runs on a billboard, two ad sets and one partner repost; the partner repost is not on the map.
   Action: Run the map audit against live captures.
   Pass: Missing placement flagged and added.
   Fail: Not found.
9. **Confirmed defect report (R8, R10).**
   Setup: Test comment on a staging post: "Since when does this city have three towers?" The file confirms the defect.
   Action: Run the incident runbook.
   Pass: Confirmed within 1 hour; every mapped placement removed the same day with times; original file and screenshots kept.
   Fail: Only the commented post is removed, or nothing is logged.
10. **Draft reply denies AI (R9).**
    Setup: Asset record says "ai_generated." Social lead drafts: "This is digital art by our studio partner."
    Action: Submit the draft for approval.
    Pass: Blocked; the correction template is used and names the defect, AI use, what was removed and the new check, within 24 hours.
    Fail: Draft approved, or no correction within 24 hours.
11. **Review feeds back (R11).**
    Setup: Close the incident from test 9.
    Action: Check the checklist version history after one week.
    Pass: A tower-count or landmark item was added, and the incident names the rule that would have caught it.
    Fail: No update.
12. **DNS: stylized art (O).**
    Setup: Cartoon poster of a fantasy castle nobody could read as a real building.
    Action: Run pre-flight.
    Pass: No landmark reference demanded; passes.
    Fail: Blocked for a missing reference.
13. **DNS: joke comment, file matches (O).**
    Setup: Comment "lol did AI make this" on an ad whose file passes every check.
    Action: Run the runbook.
    Pass: Logged as "not a defect"; ad keeps running; no correction posted.
    Fail: Ad pulled or a correction posted.
14. **DNS: one bad variant (O).**
    Setup: One of eight ad-set variants has a confirmed defect.
    Action: Run the runbook.
    Pass: That variant and its placements are pulled; the other seven keep running.
    Fail: Whole campaign paused.
