# Voice AI and Visual Interface Failures: What Changes Beyond Chat

**Chat patterns are written first. Voice and visual versions are planned, because the same failure looks different when the user listens, speaks, or looks at a screen.** Until those are written, each chat pattern notes what changes by channel, and the roadmap catalogs the planned voice and visual failures.

## Frequently asked questions

### Do chat patterns apply to voice assistants?
Mostly the skill ones do (leading, empathy, de-escalation). Timing, interruptions, and transcription are voice-specific and are in the voice catalogs.

### When will the voice and visual patterns be written?
They are in the [execution plan](../roadmap/execution-plan.md) queue.
