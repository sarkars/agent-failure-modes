# Visual: Human-Machine Interface Patterns (PLANNED)

> **Status: planned, no patterns written yet.** This page reserves the scope so visual design can be added without changing the structure.

## Scope
Screens, rich cards, dashboards, forms, avatars, and generated interfaces: what an agent shows, and how it shows it.

## Core patterns that will get a visual note or variant
The [core patterns](../../README.md) apply here too. Each already has a "Modality notes (PLANNED)" line. Examples: a dead end is a screen with no clear primary action; confetti and bright colors on a bereavement screen; an avatar that looks human without an AI label.

> **Full list:** 32 visual-design and human-oversight patterns with goals and metrics are in the [visual and oversight roadmap](../../roadmap/visual-and-oversight.md). The table below is the original short list.

## Planned visual-specific patterns
| Planned pattern | What it will cover |
|---|---|
| Cognitive overload | Too many choices, cards, or dense screens |
| Dark patterns | Hard-to-find cancel, complaint, or human options |
| Accessibility gaps | Contrast, screen readers, motion, and text alternatives |
| Misleading generated visuals | Product images or charts the agent invented |
| Trust cues and AI labeling | Avatars, synthetic faces, and unlabeled generated content |
| Rich-card misuse | Cards where plain text is faster, or the reverse |
| Form and sensitive-data design | Hosted fields, masking, and inline errors |
| Stakes-blind visual style | Playful visuals on serious topics |
