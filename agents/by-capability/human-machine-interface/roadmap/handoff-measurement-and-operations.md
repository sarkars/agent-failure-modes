# Roadmap: Human Handoff, Measurement, Model Changes, Proactive Agents, and Group Chats

> **Family goal:** A person is always reachable and informed when they need one, teams measure real outcomes, and changes to the model or prompt never surprise users.

**How these were chosen.** Customers' top frustration in the earlier research was not reaching a person. This file adds the human-handoff mechanics beyond channel switching, the measurement traps teams fall into, what happens to the experience when models and prompts change, and two surfaces on the earlier backlog: proactive or ambient agents and group chats. Each row needs research before it is written.

Flags: **V** verified source · **R** needs research · **L** legal review · **E** expert review. **In the library today:** **Covered** = a pattern already exists · **Extends** = an existing pattern covers the technical failure and a new one would add the experience or design angle and a fix · **New** = no matching pattern found by file-name and keyword search (re-check before writing) · **Written** = an HMI pattern exists. **Root cause:** Model · Reliability · Business context · Governance. **Better model alone?** Yes / Partly / No. Both columns are my judgments, not measurements. See the [roadmap README](README.md).
