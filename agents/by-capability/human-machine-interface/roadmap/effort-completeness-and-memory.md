# Roadmap: Effort, Completeness, and Memory Failures

> **Family goal:** The agent does the whole job, spends effort in proportion to difficulty, keeps what the user told it, and says so when it can't.

**Grounding (verified through search):**
- **"Laziness":** in December 2023 OpenAI said it had heard reports of GPT-4 getting lazier, that it hadn't changed the model since November, and that behaviour "can be unpredictable". A January 2024 update was described as fixing incomplete task completion. No root cause was published.
- **Underthinking:** in open reasoning models, abandoning promising lines too early was more frequent on harder problems and correlated with wrong answers (Wang et al., 2025). The study does not cover other model families.
- **Multi-turn unreliability:** across six tasks and 15 models, performance fell about 39% on average in multi-turn conversations, mostly from reliability, not capability. Models answered early and leaned on early assumptions (Laban et al., 2025).
- **Position effects:** accuracy is highest when relevant information is at the start or end of a long context and drops in the middle, even for long-context models (Liu et al., 2023).

**Most memory and context failures are already written** (links in the last column). The **gaps** are mostly about telling the user, not the loss itself: no warning of context loss, no continuity on a new session, no receipt of what was and wasn't done, and the "lazy" behaviours (partial work, deferring to the user, shrinking scope), for which I found no existing pattern.
