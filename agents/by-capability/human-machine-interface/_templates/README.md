# Pattern Template: How to Write a Failure Pattern People Can Find and Use

**The template is the format every human-machine interface pattern follows: a search-phrased title, a header table with the goal and primary metric, a before-and-after transcript, a fix you can copy, short tests, and metrics.**

- [hmi-pattern.md](hmi-pattern.md): copy this file to start a pattern.

Rules it enforces: answer in the first two sentences, use the words people search, cite only what you can verify, and include a fix with a reference design. See the [contributing steps](../README.md#contributing).
