# Age Adaptation: Goal, Metrics, and Patterns

> **Goal:** Likely minors get safe, age-appropriate behaviour, with no data collection or pressure.

## Why this family exists
Children use general-purpose bots and often say so. Privacy law and basic safety require different behaviour, not just simpler words. Have counsel and child-development experts review.

## How we measure it
Shared metrics the patterns below report against. Targets are starting points to tune on your own data, unless a source is given.
| Metric | Target | Defined in |
|---|---|---|
| Personal-data requests in minor mode | 0 | [child user treated as adult](failures/child-user-treated-as-adult.md) |
| Strong-signal detection recall | Over 90% | child user treated as adult |

## Patterns
| Pattern | One line |
|---|---|
| Child user treated as adult | Collects data and pushes sales on a likely child |
