# Incidents: Real Cases Behind the Patterns

**Each page here describes one dated, public case of an assistant failing people, what happened, and which pattern it matches.** Incident pages are evidence, not commentary: every fact has a source we opened.

## Format
Each page is `<short-name>.md` and has:

1. **What happened.** Two or three sentences, with the date and the organization as the source reports them.
2. **Sources.** Links, each marked *opened* or *read through a summary*. Prefer the original filing, ruling, regulator notice, or report over news coverage.
3. **What the sources do not say.** Anything claimed elsewhere that we could not confirm.
4. **Patterns it matches.** Links to written patterns, with one line on why.
5. **Outcome.** Only what a source states.

## Rules
- Never describe an incident you did not read about in a source you opened.
- Do not name or quote private individuals beyond what the source publishes.
- Do not guess at causes. Say "the source does not explain why."
- If no good source exists, there is no page.
