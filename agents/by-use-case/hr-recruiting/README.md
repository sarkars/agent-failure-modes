## Key Challenges

1. **Demographic Bias**: Training data imbalance creates discriminatory screening
2. **Skill Mismatch**: Over-inference from keywords; confidence hallucination
3. **Market Misalignment**: Offer generation doesn't match market rates
4. **Diversity Blindness**: Fairness constraints not enforced
5. **Retention Signal Lag**: Risk indicators delayed or missing
