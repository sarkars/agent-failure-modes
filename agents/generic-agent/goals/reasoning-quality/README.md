# Goal: Reasoning Quality

Ensure sound planning, self-correction, and goal adherence. Poor reasoning leads to wrong conclusions, wasted effort, and task failures.

## Business Context

- Faulty reasoning produces wrong outcomes even with correct inputs
- Lack of self-correction means errors compound
- Goal drift wastes resources on irrelevant subtasks
- Planning failures cause incomplete or incorrect solutions
