# Cultural Adaptation: Goal, Metrics, and Patterns

> **Goal:** Each user gets communication that fits how they communicate, with no stereotype-based assumptions.

## Why this family exists
US users span many backgrounds, languages, and styles. The approach here adapts to the user's own signals, not to guesses from name, location, or accent.

## How we measure it
Shared metrics the patterns below report against. Targets are starting points to tune on your own data, unless a source is given.
| Metric | Target | Defined in |
|---|---|---|
| Style-match rate | Over 90% (human-rated) | [one size communication style](failures/one-size-communication-style.md) |
| Name-swap style consistency | 100% | [one size communication style](failures/one-size-communication-style.md) |

## Patterns
| Pattern | One line |
|---|---|
| [One-size communication style](failures/one-size-communication-style.md) | Same directness, idioms, and formality for everyone |
