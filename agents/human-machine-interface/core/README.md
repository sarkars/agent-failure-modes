# Chatbot and AI Agent Conversation Failures: Core Patterns for Chat, Voice, and Visual

**Core patterns cover the conversation skills every AI agent needs on any channel: leading toward a next step, matching tone to the stakes, showing real empathy, de-escalating angry customers, protecting vulnerable users, and treating people fairly.** If your bot answers questions but feels boring, tone-deaf, or stuck, start with the family below that matches the symptom.

## Key Takeaways

- Ten families, each with a stated goal and shared metrics. The first written pattern in each family is linked below.
- Every pattern gives a before-and-after transcript, the cause, a fix you can copy, short tests, and metrics with alert thresholds.
- These apply to chat today. The voice and visual notes in each pattern say what changes by channel.

## Frequently asked questions

### Why does my chatbot feel boring and generic?
Usually it answers the question and stops. See answer-and-go conversation for how to add a next step and a close.

### How do I make a chatbot sound empathetic without being fake?
Name the specific problem, then act on it. Hollow empathy shows the before and after.

### How should a bot handle an angry customer?
Change tactics instead of repeating policy. See no de-escalation strategy.

### Is this legal or clinical advice?
No. Crisis, children, privacy, and disclosure patterns are design guidance. Get expert and legal review.
