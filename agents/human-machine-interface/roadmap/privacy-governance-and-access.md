# Roadmap: Privacy, Governance, Ethics, Access, and External Services

> **Family goal:** The agent handles personal data and outside services under clear rules, acts only within the rights of the person it serves, explains its limits, and keeps to its rules when pushed.

**Most of the technical side is already written.** The library has 12 governance patterns, a full tool-authorization set, 15 access-scope patterns, security and data-loss-prevention sets, external-action patterns, and memory-safety patterns (links in the last column). So this file is mainly a **map**: it shows where each concern is already covered, and lists the **gaps**, which are mostly conversation-facing (what the user sees, is told, or can do).

**Grounding (verified through search):**
- **Frameworks:** the OWASP Top 10 for LLM Applications 2025 names Sensitive Information Disclosure (LLM02), Excessive Agency (LLM06), and System Prompt Leakage (LLM07) among its ten; NIST's July 2024 Generative AI Profile (AI 600-1) lists 12 risks including Data Privacy, Information Integrity, and Human-AI Configuration. I did not read either in full.
- **Privacy rights:** California's CCPA as amended by the CPRA gives rights to know, delete, correct, and opt out of sale or sharing, and to limit use of sensitive personal information. Sources disagree on response timelines, so check the statute.
- **Rules that don't hold:** tau-bench (Yao et al., 2024) tests agents on customer-service tasks with written policies and finds strong models solve under half the tasks and are inconsistent across repeated runs.
- **Incidents:** reports of a July 2025 case in which a coding agent ran destructive commands on a production database during a code freeze, with differing record counts across sources.
- **Withdrawn guidance:** the CFPB withdrew 67 guidance documents in May 2025, including a 2022 circular on adverse-action reasons for algorithmic credit decisions. The withdrawal is described as pending further review. **I could not confirm whether the 2023 chatbot spotlight cited elsewhere in this repo was among them.**

Flags: **V** verified source · **R** needs research · **L** legal review · **E** expert review. **In the library today:** **Covered** = a pattern already exists, so no new one is planned · **Extends** = an existing pattern covers the technical failure and a new one would add the experience or design angle and a fix · **New** = no matching pattern found by file-name and keyword search. Re-check before writing. See the [roadmap README](README.md).
