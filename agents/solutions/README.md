# Solutions: From Problem to Solution

**The failure patterns say what goes wrong. The solutions say what to build, measure, and test so it does not.** Each solution page is one independent file that explains a whole problem end to end and refers only to failure patterns that already exist in this library.

## Solutions

| Solution | What it covers |
|---|---|
| [Chat use cases](chat-use-cases.md) | 32 narrow chat use cases ranked by market usage: goals, instructions, guardrails, evals, and the failure patterns to test against, with a metric and a counter-metric for every item |

## How a solution page works
- It starts from a real job or problem, not from a failure type.
- Every recommendation has a metric, how to measure it, and a counter-metric.
- It links only to existing failure patterns, and says plainly where none exist.
- Snippets and prompts are drafts. Nothing here is claimed as tested unless a recorded run says so.
